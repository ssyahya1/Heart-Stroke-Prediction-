#  Heart Disease Prediction System

A machine learning-based web application that predicts the possibility of heart disease using patient health information. The project uses a trained machine learning model and provides an easy-to-use interface developed with Streamlit.

##  About the Project

Heart disease is one of the most common health problems worldwide. Early prediction can help in taking preventive measures and making better health decisions.

This project applies machine learning techniques to analyze different health-related factors and predict whether a person is at risk of heart disease. The application takes patient details as input and provides a prediction result through an interactive web interface.

##  Features

- Interactive and user-friendly Streamlit interface
- Real-time heart disease prediction
- Displays prediction results based on patient information
- Uses a trained machine learning model
- Handles data preprocessing automatically
- Clean and simple application design

##  Machine Learning Workflow

The project was developed using the following workflow:

1. Data Collection
2. Data Cleaning and Preprocessing
3. Exploratory Data Analysis (EDA)
4. Feature Engineering
5. Categorical Data Encoding
6. Feature Scaling
7. Model Training
8. Model Evaluation
9. Model Deployment using Streamlit

##  Features Used for Prediction

The model uses the following patient health details:

- Age
- Sex
- Chest Pain Type
- Resting Blood Pressure
- Cholesterol Level
- Fasting Blood Sugar
- Resting ECG
- Maximum Heart Rate
- Exercise Induced Angina
- Oldpeak
- ST Slope

##  Machine Learning Model

The project uses a machine learning model trained on heart disease data.

The workflow includes:

- Data preprocessing
- Feature scaling using StandardScaler
- Encoding categorical variables
- Model training and evaluation
- Saving the trained model using Joblib

The saved model is integrated into the Streamlit application to make real-time predictions.
